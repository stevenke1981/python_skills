# Python Skills

AI 編碼助理專用的 Python 技能包，涵蓋 10 大主題：現代語法、非同步、資料處理、測試、打包、設計模式、CLI、效能、AI/ML、Web 開發。

## 技能列表

| Skill | 主題 |
|-------|------|
| py-modern | Python 3.12+/3.13+ 現代語法 |
| py-async | 非同步程式設計 (asyncio) |
| py-data | 資料處理 (pandas, Polars, NumPy) |
| py-testing | 測試 (pytest, hypothesis) |
| py-packaging | 打包與發布 (pyproject.toml, uv) |
| py-patterns | 設計模式與架構 (SOLID, DI) |
| py-cli | CLI 工具 (Typer, Rich, Textual) |
| py-perf | 效能優化 (profiling, memory) |
| py-ai | AI/ML 整合 (LangChain, Transformers) |
| py-web | Web 開發 (FastAPI, Pydantic v2) |
